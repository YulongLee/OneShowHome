# OneShow Home Game Runtime

This directory contains the Godot 4.x indoor world runtime. Tauri remains the
macOS shell; Godot owns movement, physics, camera, collisions, interactions,
Buddy behaviour, and room rendering.

## Run

```sh
godot --path game --editor
godot --path game
```

Controls:

- `WASD` / arrow keys: move
- `E` / space: interact
- `1`, `2`, `3`: Living Room, Kitchen, Bedroom

Farm, garden, town, world map, and social systems are intentionally outside the
first release scope.
