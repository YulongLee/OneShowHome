# OneShow Home macOS MVP 产品规格

> 版本：0.1
> 状态：Draft for implementation
> 产品范围：Phase 0 至 Phase 3

## 1. MVP 假设

如果一个数字角色能够在 Mac 桌面持续存在、延续自己的状态，并给用户提供简短而自然的互动，目标用户会在一周内多次主动回来查看它。

## 2. 平台基线

- macOS 14 及以上；
- Apple Silicon 优先；
- 桌面独立应用，不提供 Web 版本；
- 首期通过 Developer ID 签名、公证后直接分发，不以 Mac App Store 上架为目标；
- 中文为首发语言，工程结构保留国际化能力。

Intel Mac 与更低 macOS 版本在技术验证后再决定是否支持，不作为首个 MVP 的发布阻塞项。

## 3. 版本范围

### Phase 0：桌面体验技术验证

验证：

- 透明、无边框的小屋窗口；
- 窗口层级和 macOS 多桌面空间行为；
- 点击小屋打开主窗口；
- 透明区域不产生大面积误触；
- 小屋位置保存与恢复；
- `.app` 构建成功。

Phase 0 不包含 Buddy 业务、数据库和 AI。

### Phase 1：非 AI 垂直切片

实现：

- 首次启动与预设 Buddy 创建；
- 桌面小屋；
- Living Room；
- Buddy 基础动画与状态；
- 本地时间驱动的昼夜变化；
- 本地状态持久化；
- 设置、退出和数据清除入口。

### Phase 2：互动与记忆

实现：

- 文本聊天；
- AI Provider 抽象；
- 用户自备 API Key；
- 安全密钥存储；
- 聊天记录与基础记忆；
- 网络与服务异常处理。

### Phase 3：回访与发布

实现：

- 日记；
- Schedule 和离线时间补算；
- Bedroom、Kitchen、Garden 的最小表现；
- 用户主动开启的开机启动；
- 签名、公证和安装包；
- 性能、稳定性和无障碍打磨。

## 4. 核心用户流程

### 4.1 首次启动

```text
启动应用
  → 产品介绍与隐私说明
  → 输入 Buddy 名字
  → 选择预设形象和性格风格
  → 创建完成
  → 进入 Living Room
  → 引导用户将小屋留在桌面
```

首次启动应在五分钟内完成，不要求注册账号或绑定支付方式。

### 4.2 日常回访

```text
看到桌面小屋状态
  → 点击小屋
  → 进入当前房间
  → 查看 Buddy 状态
  → 互动或聊天
  → 状态和记忆更新
  → 退出主窗口，小屋继续存在
```

### 4.3 退出与暂停

- 关闭主窗口不等于退出应用；
- 菜单栏提供“隐藏小屋”和“退出 OneShow Home”；
- 隐藏小屋后状态仍可按本地时间计算；
- 用户可以关闭开机启动；
- 用户可以导出或删除本地数据。

## 5. 功能需求

### FR-001 桌面小屋

- 显示为透明、无边框窗口；
- 默认不抢占键盘焦点；
- 点击可打开或聚焦主窗口；
- 支持拖动，位置在重启后恢复；
- 支持多个 macOS 桌面空间；
- 不遮挡全屏应用；
- 非交互透明区域不应阻挡正常桌面操作；
- 在设置中可隐藏或重新显示。

具体窗口层级必须由 Phase 0 实机验证后写入决策记录，不能仅凭配置推断。

### FR-002 Buddy 创建

- 名字：必填，1–20 个可见字符；
- 形象：从内置预设中选择；
- 风格：从有限人格预设中选择；
- “性别”不是必填项；如保留，应提供“不指定”；
- MVP 创建完成后不支持多 Buddy。

### FR-003 Living Room

- 展示 Buddy、当前活动和情绪；
- 提供互动入口；
- Phase 2 提供聊天入口；
- 房间切换功能在对应房间具备内容前不展示空入口。

### FR-004 Buddy 状态

```typescript
type BuddyMood = "happy" | "calm" | "sad" | "tired";
type BuddyLocation =
  | "living_room"
  | "kitchen"
  | "bedroom"
  | "garden";
type BuddyActivity =
  | "idle"
  | "reading"
  | "cooking"
  | "sleeping"
  | "gardening"
  | "thinking";

interface BuddyState {
  mood: BuddyMood;
  energy: number;
  location: BuddyLocation;
  activity: BuddyActivity;
  updatedAt: string;
}
```

规则：

- `energy` 必须限制在 0–100；
- 状态转换必须由领域规则或明确事件触发；
- UI 不能直接修改持久化状态；
- 随机行为必须可测试，可通过固定随机种子复现；
- 应用重新启动时根据最后更新时间进行离线补算；
- 用户离开不会导致 Buddy 死亡、生病或责备用户。

### FR-005 昼夜系统

- 使用 Mac 当前时区；
- 第一版仅区分白天和夜晚；
- 默认白天为 06:00–18:00，夜晚为 18:00–06:00；
- 系统时间或时区改变后，下次状态计算自动修正；
- 视觉变化不依赖网络和天气服务。

### FR-006 本地数据

- Buddy 资料、状态、设置、聊天、记忆和日记使用 SQLite；
- API Key 不存入 SQLite；
- 数据库位于系统应用数据目录；
- 所有结构变更通过版本化迁移执行；
- 用户可以删除全部本地数据并回到首次启动状态。

### FR-007 AI 聊天

- Phase 2 才启用；
- Provider 接口与具体供应商解耦；
- AI 请求由可信后端层发起，不在 UI 中保存密钥；
- 发送前明确告知用户对话内容将传输到所选服务；
- 请求超时、限流、无余额和断网均有可理解的提示；
- AI 不可用时，Buddy 的本地状态和房间仍正常工作。

### FR-008 Memory

第一版只保存两类记忆：

- `preference`：用户明确表达且适合长期保留的偏好；
- `event`：与 Buddy 互动有关、可用于保持连续性的事件。

要求：

- 每条记忆包含来源、创建时间、重要性和最后使用时间；
- 用户可以查看和删除记忆；
- 不自动保存密码、财务、医疗或身份凭证；
- 记忆提取失败不能阻塞正常聊天。

### FR-009 Diary

- 每个自然日最多一篇；
- 日记只能基于已发生的本地事件和互动生成；
- 无足够事件时使用简短模板，不虚构用户行为；
- 生成失败可重试，不重复创建；
- 用户可以删除日记。

### FR-010 设置

至少包含：

- 显示或隐藏桌面小屋；
- 声音开关；
- 开机启动开关；
- AI Provider 与密钥管理；
- 数据导出与删除；
- 隐私说明、版本号和退出应用。

## 6. 非功能需求

### 性能

- 冷启动至可交互目标不超过 3 秒，以首批支持设备实测为准；
- 桌面小屋空闲时不得持续高 CPU 占用；
- 动画在支持设备上目标为稳定 60 FPS；
- 建立内存基线并在每个 Phase 记录，禁止无依据承诺固定低内存数值。

### 稳定性

- 应用崩溃后不损坏 Buddy 数据；
- 数据库迁移必须在事务内完成；
- 写入中断后可以再次启动；
- 主窗口关闭和系统休眠后不产生重复计时器或重复日记。

### 无障碍

- 所有交互控件支持键盘访问；
- 状态不只通过颜色表达；
- 支持 macOS Reduce Motion；
- 关键文字满足合理对比度；
- 动画和声音可关闭。

### 隐私

- 默认不采集聊天正文、记忆、日记或桌面内容；
- 不读取其他应用窗口、文件或输入内容；
- 网络请求仅用于用户主动启用的 AI 功能、更新检查和明确同意的诊断；
- 删除数据后本地内容不可从应用内恢复。

## 7. MVP 验收标准

Phase 1 发布候选版本必须满足：

1. 全新安装后五分钟内可完成 Buddy 创建；
2. 桌面小屋可见、可拖动，重启后位置恢复；
3. 点击小屋能可靠打开或聚焦 Home；
4. Buddy 至少具有 `idle`、`happy`、`sleeping` 三种可见状态；
5. 白天与夜晚视觉按本地时间切换；
6. 退出并重新启动后 Buddy 资料与状态保留；
7. 断网不影响非 AI 功能；
8. 用户可以隐藏小屋、退出应用和清除数据；
9. 自动化检查、单元测试和生产构建通过；
10. 在支持范围内至少两台真实 Mac 完成冒烟测试。

Phase 2 还必须满足：

1. 密钥不出现在源码、Git 历史、日志或 SQLite；
2. 用户明确同意后才向 AI Provider 发送内容；
3. 断网、限流、无效密钥和超时均有明确反馈；
4. 用户可以查看和删除已保存记忆；
5. AI 服务不可用时本地体验仍可使用。

## 8. 明确不验收的内容

MVP 不以以下内容作为完成条件：

- 多人社交；
- Town 或 World；
- 角色图片实时生成；
- 云同步；
- 支付；
- 完整家具系统；
- 无限对话能力；
- Mac App Store 上架。
