# ADR-0002：MVP 采用本地优先架构

- 状态：Accepted
- 日期：2026-08-09

## 背景

OneShow Home 的第一阶段目标是验证桌面陪伴和关系连续性，不需要账号、好友、云同步或多人世界。引入服务器会增加账号、隐私、成本、稳定性和运维范围，却不能直接验证核心假设。

## 决策

- Buddy 资料、状态、聊天、记忆、日记和设置默认保存在本机；
- 不建立 OneShow Home 用户账号；
- 不提供云同步；
- AI 仅在用户主动启用后访问外部 Provider；
- AI 不可用时，桌面小屋、房间、状态和本地时间逻辑继续工作；
- API Key 使用安全存储，不进入 SQLite。

## 后果

正面：

- MVP 架构和隐私边界更清晰；
- 离线核心体验可靠；
- 降低早期开发和运维成本；
- 用户数据默认留在本机。

负面：

- 更换或丢失设备时数据不会自动恢复；
- 多设备体验暂不可用；
- 用户需要自行管理 AI Provider 凭证；
- 卸载和本地故障可能导致数据丢失。

## 复审条件

- 用户研究证明跨设备恢复是留存关键；
- 正式引入社交关系；
- 需要服务端统一人格或内容安全能力；
- 建立明确的账号、加密、导出和删除方案。
